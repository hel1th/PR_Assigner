# PR_Assigner

### Условия:
- 1 работник = 1 команда (иначе путаница с назначением ревьюеров из разных команд)
- Если пользователь уже существовал, но вызывается добавление команды с ним => он переходит из одной, в другую
- Если команда уже существовала, но производится ее создание с пользователями => пользователи добавляются в текщую
- NeedMoreReviewers является вычисляемым методом PR, не хранится в бд

### Статистика
Добавлена статистика по эндпоинту `/stats/users[?team_name=]` если имя команды не указано, выводится статистика по всем
